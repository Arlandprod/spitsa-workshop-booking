# Проверка v1

Проверено на Tyoma 30 сентября 2026 года. Node.js 25.8.1, npm 11.11.0, Windows; для обычного воспроизведения рекомендуется Node 24 LTS. Lockfile закрепляет версии пакетов.

| Проверка | Фактический результат |
| --- | --- |
| `npm ci` | Чистая установка из lockfile завершилась успешно |
| `npm run typecheck` | Пройдено без ошибок |
| `npm test` | 16/16 тестов правил времени и транзакций пройдено |
| `npm run build` | Самостоятельная сборка `dist` создана без ошибок |
| `npm run test:e2e` | 6/6 сценариев Chromium пройдено именно на готовой сборке |
| `npm audit --audit-level=high` | 0 известных уязвимостей на момент проверки |
| Визуальная проверка | Просмотрены скриншоты desktop 1280px и mobile 390px |

Браузерные сценарии: запись → перезагрузка → перенос → отмена; гонка двух вкладок; изменение/закрытие дня и reset; перенос/отмена синтетической записи владельцем; мобильная форма и отображение HTML как текста; необязательные WebMCP tools через тестовый registry.

Часы тестов фиксированы на 2030-10-02 09:00 МСК; часовой пояс браузера — America/Los_Angeles. Это проверяет независимость расчётов от локальной зоны, не означает использование захардкоженной даты приложением.

Публичные исходники проверены перед публикацией на ключи/токены, credential URLs, приватные/runtime-файлы и ошибки UTF-8; содержимое дополнительно просмотрено. В проекте синтетические данные, нет клиентских материалов, `.env` и пользовательской БД. В Git используется публичный GitHub noreply-адрес.

Не выполнялись: реальный VPS/DNS/TLS-деплой, проверка доступности из РФ, ручная QA Safari/Firefox, запуск Docker-контейнера. Nginx/Docker-конфигурация подготовлена для самостоятельного запуска. Демо остаётся локальным: общей БД и настоящей авторизации нет.
